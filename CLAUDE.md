# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

vn-cphof.com — Vietnam Competitive Programming Hall of Fame. A read-only, SEO-first archive (leaderboard, profiles, contests, departments, organizations, ICPC teams) covering departmental olympiads → VOI/IOI → OLP/ICPC. **SPEC.md is the single source of truth** for functional and design decisions; DESIGN.md captures the design system; PRODUCT.md the brand. Where `design-preview.html` and SPEC.md disagree, the spec wins.

Phase 1 = this frontend only, running entirely against an in-repo mock backend. Phase 2 (real API, submissions, admin, auth) is spec'd but not built.

## Architecture

Next.js 15 App Router, React 19, TypeScript, Tailwind 4 (tokens in `globals.css` `@theme`, OKLCH), next-intl, TanStack Query, zod 4. Path alias `@/*` → `src/*`.

### Mock backend (the core pattern)

The data layer is layered so the future real backend slots in with zero component changes:

1. **`src/lib/api/schemas.ts`** — zod schemas, single source of truth for all entity shapes (SPEC §4) and API responses (SPEC §7). Types via `z.infer`. The backend must implement this contract verbatim.
2. **`src/mocks/fixtures.ts`** — fixture data: departments (official MOE unit codes with historical aliases), contests, editions, profiles (invented placeholders), achievements, ranking weights. Imports real ICPC data from `src/mocks/icpc-vn/`.
3. **`src/lib/api/store.ts`** — all query logic (ranking computation SPEC §6, filtering, cursor pagination, diacritic-insensitive search). Builds in-memory indexes over fixtures. _Deleted wholesale when the real backend lands._
4. **`src/app/api/v1/*/route.ts`** — thin route handlers wrapping store functions, validating params with zod.
5. **`src/lib/api/client.ts`** — typed fetch client for client components; reads `NEXT_PUBLIC_API_BASE_URL` so the real backend is a env-var swap.

**Server components call `store.ts` functions directly (no HTTP round-trip); client components go through `client.ts` → `/api/v1` + TanStack Query.**

### Real scraped data vs invented fixtures

`src/mocks/icpc-vn/*.json` is **real scoreboard data** generated by `scripts/scrape-icpcvn.mjs` — never edit those JSON files by hand; re-run the scraper. Org names resolve through `org-seeds.json`; the scraper fails if any scoreboard org is unmapped, keeping the registry total. Profiles in `fixtures.ts` are invented placeholders.

### i18n

next-intl with locale-prefixed URLs, `vi` default, `en` secondary (`src/i18n/routing.ts`). Middleware (`src/middleware.ts`) skips `/api`. Messages in `messages/{vi,en}.json`. Always use the navigation helpers from `src/i18n/navigation.ts` (not `next/link` directly) so locale prefixes are preserved. Vietnamese diacritics are first-class: search/slug normalization lives in `src/lib/text.ts` (`stripDiacritics`, `slugify`, `viCollator`) — reuse it, don't reimplement.

### Routes

`src/app/[locale]/` — home (leaderboard), `p/[slug]` (profiles), `contests/[slug]/[edition]`, `departments/[code]`, `organizations/[slug]`, `teams/[slug]`, `about`. Organization slugs have legacy English-slug aliases that redirect to the canonical Vietnamese-derived slug (see `orgBySlugAlias` in store.ts).

## Design system (enforced)

DESIGN.md has the full token tables. Non-negotiables:

- **Flat, restrained, archival.** No gradients, shadows, glassmorphism, gamification. One blue accent; red/green/yellow ramps appear only as data encodings (scoreboard cells, medals, dots) — never decoration.
- **No bordered boxes** for inline containers — use `bg-wash` fills. Borders only on floating layers and table hairlines.
- Only tokenized font sizes (`text-body`, `text-2xs`, `text-stat`, …) — never arbitrary `text-[..]`.
- Real `<table>` semantics for tabular data; numeric columns `tabular-nums`; tables stay SSR (SEO-first — no virtualization).
- Color never the only signal (medal pips carry G/S/B letters).
- Motion: one-time `.reveal` fade-up only; `prefers-reduced-motion` disables it.
- White text never on yellow (yellow base is light — pair with `ink` or `yellow-deep`).

## Conventions

- Fonts: SVN-Gotham (sans, local files in `src/fonts/`) + IBM Plex Mono — wired in `src/lib/fonts.ts`.
- shadcn-style primitives in `src/components/ui/` (cva + radix); shared HoF tokens (dot/avatar colors, medal pips) in `src/components/hof/tokens.tsx`.
- CSP in `next.config.ts` allows `unsafe-inline` scripts (RSC streaming requirement); tightening requires the nonce-middleware pattern — known open follow-up.
- Desktop-first; mobile/responsive pass is explicitly deferred (SPEC NFR).
