Implementation notes - for review
  1. Typography: SVN-Gotham (licensed family, provided in repo) - Book 400 / Regular 500 / Bold 700 / Black 800, loaded from src/fonts/svn-gotham/. Montserrat is the documented fallback.
  2. Approach A chosen for all 4 screens per review: dense ranked table / two-column profile rail / single results table / stats-header department page. Submission form screen skipped - Phase 2 per SPEC.md.
  3. "+ Submit a profile" button hidden until Phase 2 (resolved conflict - no dead buttons). Mode tabs use SPEC's canonical 7: Overall / IOI / APIO / ICPC / VOI / OLP / Departmental.
  4. Medal tokens always pair color with a letter (G/S/B) and count/word - color is never the only signal (NFR-6).
  5. Top-3 marker: 3px blue inset hairline + accent rank numeral, per wireframe note "understated, not gamified".
  6. Avatars & department seals are flat initial-based placeholders; real photos/seals drop in without layout change. Department dot colors are deterministic per-department tokens.
  7. Data is sample fixture content from the wireframes (not real results). VOI tiers shown in Vietnamese (Giải Nhất/Nhì) matching SPEC i18n direction.
  8. Interactions in this preview: top dark bar switches screens; any person row / notable card opens the Profile screen. Filters, tabs, search, language toggle are visual only.
